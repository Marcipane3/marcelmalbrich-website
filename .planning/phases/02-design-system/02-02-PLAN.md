    Render the MM monogram as a Next.js `<Link href="/">` wrapping a `<span>` styled as a 38×38 circle with: `background: linear-gradient(140deg, var(--teal-bright), var(--teal-deep))`, `color: #fff`, `display: grid`, `place-items: center`, `border-radius: 50%`, `font-family: var(--font-serif)`, `font-weight: 600`, `font-size: 16px`, `box-shadow: var(--shadow-brand)`. The wrapping `<Link>` adds `aria-label="Home"`.

    This component must be trivially swappable: the NavBrand renders exactly one child element (the span or future Image). The parent nav layout must not depend on its internal markup — only on its outer element being a link.

    **Nav links:**
    Render the 5 links using Next.js `<Link>`: About → `/about`, Experience → `/experience`, Projects → `/projects`, Personal → `/personal`, Contact → `/contact`.

    For the active state: use Next.js `usePathname()` from `"next/navigation"`. Since usePathname is a client hook, extract the link list into a small `"use client"` child component called `NavLinks` (inline in the same file). NavLinks renders the 5 `<Link>` elements with className that adds `border-b-2 border-[var(--teal)]` when `pathname === href` and `border-b-2 border-transparent` otherwise. Both states also include `text-[var(--ink)]` and `hover:text-[var(--teal)]` transitions. Font: `font-sans text-[15px] font-[500]`.

    **Header layout (two-tier):**

    Outer `<header>`: `sticky top-0 z-50`. Background: translucent off-white + backdrop blur — use inline style `background: rgba(244,247,247,0.88)` and `backdropFilter: "blur(10px)"` (this is the only translucent surface on the site per handoff §8). Add a bottom border: `border-b border-[var(--line)]`.

    Inner container `<div>`: max-width 1120px, centered, horizontal padding matching `--gutter` (48px on desktop, 16px on mobile). Use Tailwind: `mx-auto px-4 md:px-12 max-w-[1120px]`.

    Inside the container, a flex row: NavBrand on the left, NavLinks on the right. The NavLinks area on **mobile** must be horizontally scrollable — use `overflow-x-auto` and hide the scrollbar with `-webkit-overflow-scrolling: touch`. Wrap NavLinks in a `<nav aria-label="Main navigation">` element. NavLinks renders as a flex row with `gap-6` (`--space-6` = 24px) and `whitespace-nowrap` so links don't wrap on small screens.

    Per D-09 (CONTEXT.md): the NavBrand placeholder must be swappable without touching nav layout. Per D-07: mobile uses horizontal scrollable bar, not hamburger.
